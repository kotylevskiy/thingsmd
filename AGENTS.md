# Write boundaries

- NEVER change anything outside this repository or a marked disposable test vault without the user's explicit permission for that specific action.
- This includes personal vaults (especially Projects), installed plugins, settings, backups, temporary files, and Obsidian profiles outside those boundaries. Put development artifacts and temporary profiles inside this repository or the disposable vault.
- Permission for an earlier migration, installation, or release does not authorize later external changes. Do not install fixes into personal vaults unless explicitly requested.

# Development

- Do not change `README.md` without the user's explicit request or approval.
- Change plugin source in `plugin/`; `dist/` is generated by `npm run build`.
- Preserve unsaved drafts and surrounding Markdown. Reject edits that would overwrite external changes.

# Releases

- When creating a GitHub release, set its title explicitly to `ThingsMD <version>` (for example, `ThingsMD 0.8.0`).

# Testing

- For code changes, run `npm run check` and `npm run build`; add meaningful regression tests.
- Verify affected flows in real Obsidian: lists, Live Preview, and Reading view. Check mobile changes with mobile emulation and relevant WebKit fixtures.
- Use `waitForAsync` for asynchronous storage assertions, not async callbacks to Playwright's `waitForFunction`.
- Report results and limitations; distinguish mocked tests, real Obsidian, and emulation.

# Disposable Obsidian

- Create a marked temporary vault with `npm run dev:vault`; set `THINGSMD_TEST_VAULT` to its output. Never mark existing vaults or bypass guards.
- Launch a separate Obsidian instance with a fresh temporary profile and localhost remote debugging. Set `THINGSMD_DEBUG_URL` to its endpoint.
- Run `npm run deploy`, then `npm run dev:open` to load the built plugin. Run affected UI suites; use `npm run test:all-ui` for full regression testing.
- Run UI drivers sequentially; clean fixtures and restore settings, viewport, and emulation. Leave the isolated instance open afterward.
- Never test against personal vaults or profiles.
